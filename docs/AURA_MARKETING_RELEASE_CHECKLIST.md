# Aura Marketing Hub — Release checklist

- [ ] CI production bundle passes.
- [ ] Render deployment reaches Live.
- [ ] Authenticated route access and enterprise scoping are verified.
- [ ] Create, list, update and delete operations are verified against production PostgreSQL.
- [ ] External connectors are configured and independently tested before being marked active.
- [ ] Social publishing, comment moderation and growth actions are enabled only through supported permissions and platform-compliant APIs.
